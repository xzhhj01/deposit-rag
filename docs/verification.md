# 검증 결과 — 금리 돋보기

요구사항 정의서 4장의 확인 항목을 실행 결과로 증명한다. 결과는 통과 · 실패 · 미확인으로 기록한다.

- 자동 검증: `python scripts/verify.py` → **27 / 27 통과** — 항목별 실제 출력은 [verification_results.md](verification_results.md)
- 화면 증명: 아래 [화면 증명](#3-화면-증명-캡처) — 캡처 15장 (`docs/screenshots/`)
- LLM 답은 실행마다 조금씩 다르다. 판정 근거에 실제 출력을 남겼고, 흔들리는 사례는 [설계 노트](design_notes.md)에 기록했다.
