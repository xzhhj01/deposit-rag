# 요구사항 정의서 — 금리 돋보기

AI 코어 프로젝트 2회차 · RAG 기반 도메인 지식 서비스

## 1. 도메인과 선택 근거

**도메인**: 은행 · 저축은행 예금 · 적금 상품 (금융)

**서비스 한 줄 정의**: 광고 금리가 아니라 내가 실제로 받을 금리를, 공시 근거와 함께 알려 주는 예·적금 도우미

| 선택 조건 | 내용 |
|---|---|
| 항목 메타데이터 | 금융감독원 금융상품한눈에 Open API — 정기예금 435개(은행 40 · 저축은행 395), 적금 336개(은행 60 · 저축은행 276), **합계 771개**, 공시월 2026-10. 속성: 금융사 · 상품명 · 가입 방법 · 가입 대상 · 기간별 기본/최고금리 · 단리/복리 · 우대조건 원문 · 만기 후 이자율 · 유의사항 · 한도 |
| 외부 문서 출처 | ① 한국어 위키백과 API (CC BY-SA 4.0) — 금융 개념 · 금융사 문서, 질문 시점 수집 ② 예금보험공사 예금자보호제도 안내장 · 리플릿 PDF ③ 한국은행 경제금융용어 800선 PDF |
| 근거가 필요한 질문 | ① "우리SUPER주거래적금 급여이체 우대 몇 %p?" — 모델은 0.5%p라고 단정(정답 0.7%p) ② "저축은행 예금은 얼마까지 보호?" — 모델은 5,000만 원(2025-09-01부터 1억 원) ③ "카카오뱅크 영업 시작일?" — 모델은 2017-04-03(정답 07-27) ④ "대중교통 미션 달성 방법?" — 공시에 없어 '모른다'가 정답 ([RAG 전후 비교](rag_comparison.md)) |
| 위험 도메인 여부 | **위험 도메인(금융)**. 면책 문구: "본 서비스는 금융감독원 공시 자료를 바탕으로 한 참고 정보이며, 금융상품 가입 권유나 전문가 상담을 대신하지 않습니다. 실제 금리와 조건은 가입 전 해당 금융사에서 확인하세요." — 화면 상단 고정 |

**항목 텍스트 설계** — 사용자는 상품을 금융사 · 유형 · 가입 대상 · 가입 방법 · 우대조건("대중교통", "급여이체 없이")으로 찾는다.
그래서 상품 1개를 `상품명 · 금융사(금융권) · 유형(단리/복리) · 가입 방법 · 가입 대상 · 기간별 금리 · 우대조건 · 만기 후 이자율 · 유의사항 · 한도`로 묶는다.
금리 크기 비교("3% 넘는")는 임베딩이 못 하므로 숫자는 메타데이터 필터로 처리한다.

## 2. 기능 요구사항

필수 기능은 정의서 문구를 유지하고, 도메인에 맞게 표현만 바꾸었다. "구현 위치"는 주요 코드 파일이다.

| F2002 | 색인 | 메타데이터 색인 (RAG 1) | `product_meta` 컬렉션에 상품 1개 = 청크 1개, id = `유형:금융사코드:상품코드`. 재색인 시 덮어쓰기. 색인 건수 화면 표시 | 필수 | store/vectordb.py · scripts/build_meta_index.py | 완료 |
